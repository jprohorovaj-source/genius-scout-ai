# GeniusScout AI

**GeniusScout AI — инструмент семантического поиска и анализа научных публикаций с автоматической подготовкой инженерного отчёта.**
---

## Задача

Инженеру и студенту ML нужно быстро собрать актуальные препринты по теме, отсеять нерелевантные работы и получить читаемый обзор со ссылками на оригиналы.

Вручную это означает поиск по ArXiv, просмотр аннотаций и перевод. GeniusScout AI закрывает этот цикл одним запросом: система сама ищет статьи, оценивает смысловую близость к теме и формирует отчёт.

---

## Пайплайн построен как набор независимых модулей, а не как один скрипт.

1. **Разбор запроса**  
   `ArxivCollector` при необходимости дополняет формулировку техническим контекстом (`python`, `machine learning`, `library` и т.д.), чтобы снизить ложные совпадения по омонимам.

2. **Сбор публикаций**  
   Запрос уходит в ArXiv API. Для каждой статьи сохраняются title, abstract, авторы, дата, PDF и идентификатор.

3. **Семантический шлюз**  
   `SemanticGate` на CrossEncoder (`ms-marco-MiniLM-L-6-v2`) оценивает пару «запрос + title/abstract». В отчёт попадают только работы выше порога из `config.py`. Логируется score каждой статьи: PASS / REJECT.

4. **Локальная векторная база**  
   `VectorStoreManager` кодирует документы моделью `intfloat/multilingual-e5-large` с корректными префиксами E5 (`query:` / `passage:`), нормализует эмбеддинги и кладёт их в FAISS `IndexFlatIP` (cosine similarity). Индекс можно сохранить и загрузить с диска.

5. **Инженерный отчёт**  
   `GeniusScoutAgent` собирает markdown: тема, проверенные публикации, перевод названия и аннотации на русский, авторы, дата, ссылка на PDF.

6. **Интерфейс и запуск**  
   Тот же агент доступен в Streamlit и Gradio. Агент кэшируется (`st.cache_resource`), чтобы модели не перезагружались на каждый клик. Есть `Dockerfile` и конфиг для Hugging Face Spaces / Streamlit Cloud.

---


## После запуска по теме (например, `Vision Transformer`) пользователь получает:

- список публикаций, прошедших Semantic Gate;
- названия и аннотации на русском с оригинальным title;
- прямые ссылки на PDF ArXiv;
- локальный FAISS-индекс по отобранным работам;
- полный лог этапов (поиск, фильтрация, индексация).

Если статей нет или ни одна не прошла порог релевантности, система явно сообщает об этом, а не подставляет пустой или выдуманный результат.

Конфигурация вынесена в `config.py`: размер выдачи ArXiv, модель эмбеддингов, CrossEncoder, порог Semantic Gate, `top_k`.

## Что реализовано:

**Модульная архитектура.** Коллектор, шлюз, векторное хранилище и агент разделены по файлам. Агент только оркестрирует шаги, без смешивания поиска, скоринга и UI.

**Двухступенчатая фильтрация.** Сначала отбор через ArXiv, затем попарная оценка CrossEncoder. В контекст отчёта не попадает «всё, что вернул поиск».

**Корректная работа с E5.** Для запросов и пассажей используются разные префиксы. После L2-нормализации inner product в FAISS совпадает с косинусной близостью.

**Прозрачный Semantic Gate.** Порог задаётся конфигом, устройство выбирается автоматически (`cuda` / `cpu`), по каждой статье пишется числовой score.

**Устойчивость к сбоям.** Ошибки ArXiv не роняют процесс: возвращается пустой список и понятное сообщение. Сбой перевода не ломает отчёт — остаётся английский оригинал.

**Практичный UI.** Streamlit не пересоздаёт тяжёлые модели на каждый запрос. Gradio даёт отдельную визуальную оболочку поверх того же `GeniusScoutAgent`.

**Готовность к показу.** Есть `requirements.txt`, Docker, инструкция для Streamlit Cloud и исходный ноутбук версии 10.5.

## Структура репозитория

```text
genius-scout-ai/
├── agent_core.py              # оркестратор: поиск → gate → FAISS → отчёт
├── collector.py               # ArXiv API и расширение запроса
├── gate.py                    # CrossEncoder Semantic Gate
├── vector_store.py            # E5 + FAISS
├── knowledge_compiler.py      # извлечение датасетов, фреймворков, метрик
├── config.py                  # модели, пороги, лимиты выдачи
├── streamlit_app.py           # веб-демо
├── app.py                     # Gradio-интерфейс
├── taxonomy.json
├── requirements.txt
├── Dockerfile
└── genius_scout_ai (V10.5).ipynb
```

## Как запустить

```bash
git clone https://github.com/jprohorovaj-source/genius-scout-ai.git
cd genius-scout-ai
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Gradio:

```bash
python app.py
```

Docker:

```bash
docker build -t genius-scout-ai .
docker run -p 7860:7860 genius-scout-ai
```

При первом запуске загрузятся модели Hugging Face (E5-large и CrossEncoder). Нужен интернет для ArXiv и скачивания весов.

## Пример

Запрос: `Vision Transformer`

Система находит препринты, отбрасывает слабо связанные с темой, сохраняет прошедшие работы в FAISS и возвращает отчёт со ссылками на PDF.
